用容器提供同一個網頁

先啟動 Docker Desktop。在專案根目錄執行下列指令；這是網頁的 Docker 延伸示範，教材的三個練習另放在 practice 資料夾。

第一次建置需要下載 Python 映像
docker build -t web-homework .
docker run -d --name web-homework-site -p 127.0.0.1:8080:8000 web-homework

開啟 http://localhost:8080。8080 是電腦的連接埠，8000 是容器內伺服器的連接埠。

若上一個步驟的 Python 伺服器仍在執行，請先用 Ctrl + C 停止，避免 8080 被占用。已建立過此容器時，改用 docker start web-homework-site。

三個容易混淆的地方

網頁檔案和網站，有什麼不同？

HTML 是檔案。瀏覽器可以直接讀它，也可以透過伺服器取得它。GitHub Pages 提供網站託管，讓別人透過網址開啟你的檔案。

Image 和 Container 有什麼不同？

Image（映像）是建立容器的範本；Container（容器）是依照映像建立的執行實例。同一個映像可以建立多個容器。

Commit 等於上傳嗎？

不是。Commit 將變更記錄在本機 Git 儲存庫；Push 才會把本機提交傳到設定好的遠端儲存庫。
